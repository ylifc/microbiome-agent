# Microbiome Agent 0.2.5 完整说明书

本套文档对应 2026 年 10 月 19 日公开的 Microbiome 0.2.5 r10。说明书依据该版本源码、接口合同和既有验收记录编写，包含安装、宿主适配、具体使用、权限与恢复、软件数据库、分析方法及开发验证。

本次公开文档更新将完整手册加入 agent ZIP 的 `manual/`，保留引擎 `bundle/` 和原始验收证据。正文中的初始 ZIP 摘要属于历史基线；当前下载包使用同一 Release 的 `.sha256` 文件校验，现行大小及文件项见仓库 `release-manifest.json`。

## 如何阅读

- 双击 `index.html`：离线浏览，左侧筛选目录，使用 Ctrl+F 或 ⌘F 全文查找。点击流程图可打开独立 SVG 放大查看。
- 打开 `Microbiome Agent 0.2.5 完整说明书.docx`：可编辑 Word 版本，带标题导航、可点击目录和页码。不同办公软件的分页可能略有差异。
- 打开同名 `.md`：完整 Markdown 原稿，适合版本管理、搜索和继续编辑。
- 查看 `diagrams/`：8 张图均提供 PNG、SVG 与 Mermaid `.mmd` 源文件。Mermaid 描述同一逻辑关系，具体自动布局随渲染器变化；SVG/PNG 保留本书的确定布局。
- 查看 `reference/`：软件、数据库、宿主 Skill 和工作流的机器可读清单，含源文件位置与摘要。清单中的文档版本不等于实际安装的软件版本。
- 查看 `chapters/`：五篇分章原稿，可单独修改后重新整理。

## 使用范围

说明书中的 `/work/...` 是示意路径，需要替换为实际执行机器的路径。自然语言示例需要用户根据真实意图发送，不构成预先存在的批准。正文分别标明已经实测、源码支持和方法参考；目录中收录某软件，不表示该软件已安装，或所有科学分析路线已通过端到端验证。

本套文件是说明书资料包，不是 agent 安装包。原始 agent 发布入口为 [Microbiome Agent v0.2.5](https://github.com/ylifc/microbiome-agent/releases/tag/v0.2.5)。完整源码位于发布的源码归档和 agent ZIP 的 `bundle/source/`。

本次写作没有运行真实样本分析、安装科学依赖或修改用户项目的审批及冻结状态。工程验收章节记录的是该版本已经存在的验证证据。
